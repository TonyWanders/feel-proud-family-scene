## What it does

`main.py` (Python 3.13, standard library only) writes one short family scene to `/output/entry.txt`: a small domestic moment, warm, funny and heartfelt, written to make a proud judge smile. It is deterministic and uses no network.

The scene is built around one telling detail: Dad burns the Sunday toast on purpose so Mum can scold him for doing it wrong for thirty years, and the child narrator keeps the secret that he does it for the laugh. The warmth is in the thirty years and the shared wink; the joke is in the burnt toast; the heart is in a family that knows each other well enough to play the same small scene every week.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The output is 203 characters across two lines, inside the 1 to 280 character gate.
